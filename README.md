# 파리 산책하기 — Godot 4 포트 (실험용 프로토타입)

웹 버전 [파리 산책하기](https://smkim77.github.io/paris-walk/)(`D:\_work\paris-walk\index.html`)를
Godot 4로 옮겨 본 첫 번째 플레이 가능한 버전입니다. 웹 버전은 그대로 두고, 이 폴더는 별도 실험입니다.

## 실행하기

이 PC에는 Godot 4.7.2 (.NET/Mono 빌드)가 winget으로 설치돼 있습니다. GDScript만 쓰므로 일반 빌드여도 됩니다.

- **에디터로 열기**: Godot 실행 → 프로젝트 관리자에서 *가져오기* → 이 폴더의 `project.godot` 선택 → F5
- **바로 실행 (명령줄)**:

  ```bash
  "$LOCALAPPDATA/Microsoft/WinGet/Packages/GodotEngine.GodotEngine.Mono_Microsoft.Winget.Source_8wekyb3d8bbwe/Godot_v4.7.2-stable_mono_win64/Godot_v4.7.2-stable_mono_win64.exe" --path "D:/_work/paris-walk-godot"
  ```

- 테스트용: `-- --autoplay` 를 붙이면 시작 화면 없이 바로 걷기 시작합니다 (헤드리스 점검에 사용).

조작: ← → / A D 이동 · ↑ ↓ / W S 속도 · Space 점프 · Enter 또는 버튼으로 시작/다시 걷기 (Space로는 재시작 안 됨) ·
P/Esc 일시 정지 · M 소리. 마우스/터치: 좌우 드래그로 이동, 상하 드래그로 속도, 짧게 탭하면 점프.

## 구조와 방식

| 파일 | 내용 |
| --- | --- |
| `game.gd` | 게임 전체: 트랙 생성, 갱신, 충돌, 렌더링, HUD, 시작/게임 오버 화면 |
| `sfx.gd` | 임시 효과음 — 시작할 때 짧은 PCM 클립으로 합성해 두고 재생 |
| `main.tscn` | `Game`(Node2D) + `Sfx` 노드 |
| `fonts/korean.tres` | 한글 시스템 폰트(SystemFont: 맑은 고딕 → Apple SD Gothic Neo → Noto Sans CJK KR …) |

**진짜 3D 대신 2D 의사 3D를 선택한 이유**: 원작이 OutRun식 세그먼트 렌더러라서, 투영·커브·세그먼트별 그리기 순서를
거의 한 줄씩 옮길 수 있고 결과 화면이 원작과 똑같이 나옵니다. 3D로 가면 모든 그림(개, 비둘기, 건물 정면, 랜드마크)을
메시/스프라이트로 다시 만들어야 해서 "일단 해 보기"에는 너무 큽니다. 모든 도형은 매 프레임 하나의 삼각형 배열로
모아서(`fill`/`flush`) `RenderingServer`에 한 번에 넘기므로 GDScript에서도 가볍게 돕니다.
렌더러는 Compatibility(OpenGL)라 웹/모바일 내보내기와도 맞습니다.

## 지금 되는 것

- 걷는 사람 뒤에서 본 보도: 커브, 좁아지는 구간, 오스만 건물 정면·차양·모퉁이, 가로수(둥근/네모/세로형), 가로등, 모리스 기둥
- 장면 전환(센강 다리 · 분수/오벨리스크 광장 · 대로)과 그 뒤 좌우가 뒤바뀐 거리
- 랜드마크 5곳(에펠탑, 개선문, 루브르, 노트르담, 사크레쾨르)과 파란 거리 표지판, 거리 이름 표시
- 위험 요소: 개똥(갓 싼 것의 김, 파리 떼 반경), 성격이 다른 개 6종, 노상방뇨 행인과 오줌 웅덩이,
  가장자리에 오래 붙어 걸으면 나타나는 행인, 비둘기 똥(땅의 표적 원 + 떨어지는 똥), 횡단보도의 차·자전거, 카페 테라스 테이블
- 구두 3켤레, 맞으면 속도 70%로 떨어짐, 무적 깜빡임, 화면 흔들림·색 번쩍임, 대사 텍스트
- 점수 = 미터 × 속도 배율(60% ×0.5 … 140% ×2), 거리에 따른 가속, 느리게 걸으면 비둘기 증가,
  속도 게이지(km/h·배율), 걷기→달리기 애니메이션, 점프
- 게임 오버 화면(장소별 메시지, 최고 점수), 일반/어려움 최고 점수를 각각 로컬 저장(`user://paris_walk.cfg`)
- 일시 정지, 소리 끄기

## 아직 안 된 것 (웹 버전과 비교)

- **어려움 모드 내용**: 스위치와 별도 최고 점수, 연기 낀 하늘만 있음. 불타는 쓰레기통/더미, 화염병(던지는 자전거·약탈자),
  불탄·약탈된 건물, 불타는 차, 약탈자 무리, 폭동 BGM은 다음 단계
- **소리**: 효과음은 임시 합성음. 아코디언 BGM·곡 전환, 거리 소음/살수차/파리/수다 등의 환경음, 스테레오 패닝 없음
- 살수차(물벼락), 차도 옆을 달리는 자전거(배경), 테라스에 앉은 손님
- 온라인 순위표(Supabase)와 프로필 — 붙이려면 `HTTPRequest`로 같은 REST API를 호출하면 됨
- 모바일 다듬기(세로 고정, 안전 영역), `prefers-reduced-motion` 대응
- 내보내기 프리셋: 아직 없음. **주의**: 설치된 것은 .NET(Mono) 에디터인데, Godot 4의 .NET 에디터는 웹 내보내기를 지원하지 않습니다.
  웹으로 내보내려면 일반(표준) Godot 에디터로 이 프로젝트를 열면 됩니다(GDScript만 써서 그대로 열림).
  또 한글 폰트를 시스템 폰트로 쓰고 있어서, 웹/모바일로 낼 때는 Noto Sans KR 같은 OFL 폰트 파일을 `fonts/`에 넣어야 합니다.
