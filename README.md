# 파리 산책하기

그저 파리를 느긋하게 산책하고 싶을 뿐인데, 거리는 그냥 걷게 두질 않습니다.
개똥과 오줌 웅덩이, 머리 위 비둘기, 횡단보도의 차와 자전거, 카페 테라스와 살수차까지,
어쩔 수 없이 피해 가며 걸어야 하는 브라우저 게임입니다.
에펠탑에서 사크레쾨르까지 파리 명소를 지나며 최대한 멀리, 높은 점수를 노려 보세요.

## 조작

- ← → / A D: 좌우 이동
- ↑ ↓ / W S: 걷는 속도 (빠를수록 점수 배율이 높아요)
- Space: 점프 (똥·오줌을 뛰어넘기, 착지하면 바로 다시 점프 가능)
- P: 일시 정지
- 휴대폰: 좌우 드래그로 이동, 위아래 드래그로 속도, 탭으로 점프, II 버튼으로 정지

## 파일

- `project.godot`, `*.gd`: 게임 원본 (Godot 4 프로젝트)
- `docs/`: GitHub Pages에서 실제로 서비스되는 웹 빌드
- `export_presets.cfg`: `docs/`를 만드는 웹 내보내기 설정 (`Web` 프리셋)

게임을 고친 뒤에는 Godot 4.7.2(표준판)에서 `Web` 프리셋으로 내보내고 `docs/`도 함께 커밋하세요.
자세한 개발 노트는 `DEVELOPMENT.md`에 있습니다.
